## Pendientes
Edita config.js para agregar nombre, dirección y enlace de ubicación y enlace del álbum. Los botones aparecen al proporcionar una URL https válida. Música pendiente, no incluida.

La selección de team es obligatoria; nombre y buenos deseos son opcionales. WhatsApp abre un mensaje dirigido a +52 613 118 3963; el invitado debe enviarlo. No hay base de datos ni registro automático de asistentes. Los datos del formulario no se guardan localmente.

El álbum necesita un servicio externo con carga habilitada; este proyecto no recibe archivos. Las fuentes usan Google Fonts, con tipografías de respaldo si no hay conexión.
